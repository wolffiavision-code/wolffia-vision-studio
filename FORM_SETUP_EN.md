# Dataset request form setup

Use a Google Forms responder link so applicants do not need an email application. The owner must sign in and publish the form.

1. Create a form while signed in as wolffia.vision@gmail.com.
2. Ask for name, optional affiliation, contact email, requested dataset, intended use and agreement to the stated data terms. Do not request passwords or unnecessary personal information.
3. State purpose, contact and retention policy. Keep response summaries private.
4. Under Responses, enable notifications for new responses. This is an arrival notification, not automatic forwarding of the full response.
5. Publish with the intended responder access. Copy the responder URL, not an editor URL. Test in a signed-out browser.
6. Set form_url in the website's form-config.json. Set the same URL in the application's config/request_form.json.
7. Submit a test request. Send approved applicants the download link and password separately. Never commit passwords. Monitor expiring download links.

Publication does not establish rights to the requested data.
Official guides: [Publish a form](https://support.google.com/docs/answer/2839588?hl=en), [Response notifications](https://support.google.com/docs/answer/139706?hl=en).
