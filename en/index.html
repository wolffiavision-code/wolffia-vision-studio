05 / ADAPT TO YOUR IMAGES

Custom classes and fine-tuning

Define YOLO class names and box labels, then train on your own images. The standard example uses vegetative, flowering and dead.

nc: 3
names:
  - vegetative
  - flowering
  - dead

Changing YAML alone does not teach a model new classes. Annotated data and training are required. Match inference YAML class IDs and their order to the trained model; automatic consistency checking does not cover every combination.

GUI Fine-Tuning

Adapt existing weights to explore differences in species, strains, magnification, lighting or backgrounds. Updates do not guarantee improved accuracy: evaluate on held-out test data. Current segmentation is binary target/background, not multiclass mask training.

Implemented / checked

GUI construction, data preparation and selected self-tests, not independent accuracy or complete cross-PC evaluation.

Applying the workflow to other duckweeds

The same detection, segmentation and measurement workflow may be applicable to Wolffiella, Lemna, Spirodela and Landoltia with suitable annotated data and models. Direct transfer of the supplied models and accuracy on these genera are not validated.

In preparation

Technical scope and specifications

ItemVerified scope
OS / runtimeWindows x64 application built and self-tested on the development PC. Other Windows versions and Python-free PCs remain unverified.
CPU / GPUCPU or compatible NVIDIA CUDA GPU selection. Build: PyTorch 2.12.1+cu130. Recommended RAM/VRAM and minimum driver versions are not established.
StorageSee the release information below for setup size. Allow extra space for installation, models, outputs and training.
Input imagesJPG/JPEG, PNG, BMP, TIFF, WEBP. HEIC/HEIF depend on an additional decoder. Full format coverage in the EXE is not verified.
AnnotationYOLO: images and labels, matching TXT names (class_id, x_center, y_center, width, height; coordinates normalized 0–1). Masks: images and masks with matching PNG names.
ModelsYOLO .pt and app-compatible SegFormer-B0 / LRASPP-MobileNetV3 checkpoints, not arbitrary architectures.
OutputsDetection/crop images, masks, Original / Overlay / Mask / RGBA montages, normalize images, CSV, NPZ, JSON and distribution HTML, depending on the task.
EvaluationYOLO: TP, FP, FN, WC (wrong class), precision, recall, F1 and confusion matrices. Training mAP and test-workspace metrics are distinct. No public accuracy benchmark is available.
Processing / networkImage processing runs locally. Model retrieval may use the network; all dependency communication has not been audited. This website has no image-upload feature.
Shape sortingMF: mother-frond candidate; DF: daughter-frond candidate; Edge: truncated/non-elliptical candidate. Latest source uses PCA, 1–3 groups and ellipse agreement with per-image HTML audits, not biological identification.

Getting started

  1. Check availability

    The public binary URL is not set. Once available, verify the version and SHA-256.

  2. Install and launch

    Run Setup.exe and choose a location. Open Japanese or English from the Start menu.

  3. Try a sample

    Open Inference / Processing → YOLO. Select images, weights and matching YAML, run and inspect results.

Back up presets, added models and results before updating; review the change log and repeat a known sample afterward.

Guidance and FAQ

This page provides public getting-started guidance. READMEs, Word manuals and developer reports will be linked after version/disclosure review.

Do I need programming knowledge?

Routine workflows use the GUI. Setup, model/data preparation and troubleshooting may require technical assistance.

Do I need a GPU?

CPU is selectable. Runtime depends on the model, image size and computer; no throughput guarantee is provided.

Can I train on my own images or add classes?

YOLO supports class names, box labels and training data for custom training. Editing YAML alone is insufficient. Masks are currently binary.

Can I use plants other than Wolffia?

Potentially. Annotate target-species images with boxes or masks; for YOLO, configure dataset paths and class names in YAML, then train or fine-tune. Define imaging conditions and how roots/fronds are labeled, and evaluate on held-out images. Editing YAML alone does not teach new species or classes.

Where are results saved?

In the local output folder selected for each task. YOLO also offers a yolo folder under the input directory. Producing output does not establish correctness.

How are MF and Edge distinguished?

Not by elongation alone. Latest source compares masks with complete fitted ellipses. Segmentation errors also reduce agreement, so inspect the images and audit.
